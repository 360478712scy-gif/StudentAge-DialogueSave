# 2026-10-09 字体与存档范围（0.2.12，已本机安装／未发布）

新增配置并排放在模组配置：对话字体（模组字体默认／原版字体）和 ADV 存档界面（全局启用／仅对话中启用默认／不启用）。两项使用设置草稿，应用写入、取消放弃；恢复默认设模组字体＋仅对话中。新增配置不覆盖已有跳过、音量等偏好。

## 行为

| 范围 | 对话中入口 | 主界面、对话外 Esc |
| --- | --- | --- |
| 全局启用 | ADV；保存 DSAV，原版分类只读取 | ADV；操作原版手动／快速档 |
| 仅对话中启用 | ADV；保存 DSAV，原版分类只读取 | 原版式，无插件百叶，保留对话存档入口 |
| 不启用 | 原版式，独立对话存档子页 | 原版式，保留对话存档入口 |

对话中原生 SaveView 强制读取，同时 SaveGame 前缀拦截原版保存；原版式 DSAV 子页拥有独立保存状态，不继承原生读取标志。标题保存禁止，原版分类无论来源均只读，空读取槽不写入。同类再次点击不切页。

字体只影响 ADV 正文与姓名，普通／CG 内容各保存自己的原生字体；切回原版恢复字体和材质。预览跟随草稿切换。布局源码核验：配置两列，字体／范围同排，末排速度卡224高，内容底740不超750；按钮文字自动适配。**这不是游戏画面验收。**

全局原版保存另行写新物理编号，移动排列及删旧前核验确认目标的文件名／时间；确认前后目标改变时保留文件并提示。原生快速读取页不提供复制／交换（原版复制会改成手动类型），仍支持读取／备注／删除。原版式存档页的确认框保留原版，避免对白 ADV 风格导致范围之外的百叶动画。
