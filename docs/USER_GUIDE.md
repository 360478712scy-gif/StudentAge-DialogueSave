# 学生时代 · 对话存档

独立 BepInEx 5 插件。开发中的版本，不修改游戏资源包，不替换或合并 UP、音频等其他插件。

## 界面

- 原版读档页保留“手动存档｜自动存档｜快速存档”，仅在左侧增加独立“对话存档”。
- 顶部始终为“对话存档｜手动存档｜自动存档｜快速存档”；入口不会改名为“返回存档”。选中对话存档后，下方另列其手动、自动、快速二级分类，继续使用原版九宫格。卡片显示说话人与当前台词摘要。
- 原版保存页在“手动存档”左侧增加“对话存档”。对话右下角工具栏提供保存、加载、快速保存、快速加载；Esc 菜单只增加原版样式的“保存游戏”“加载游戏”，不放快捷键图标。
- 默认请求键位 S/L/H/J，遇到对话中的实际绑定冲突自动避让；当前原生 S 用于向下导航，保存采用 K，其余为 L/H/J。按钮白色按键框显示实际绑定。
- 保存成功后留在保存页并更新卡片，手动关闭才回到对话；读档页可直接切换原版手动、自动、快速存档。
- 读档会放弃当前进度，不要求当前状态可以保存。保存和读档不弹右侧气泡，真实错误在本页底部或原生错误框显示。
- 卸载插件后新增界面消失；对话档保留。

## 可选 ADV 阅读界面

首次启用选择原版或 ADV，设置中的“对话界面”可随时切换。ADV 使用淡暖白渐隐底、黑字、逐字浮现；CG 使用更低的暗底、大字及居中的姓名和对白。点击未完成的句子先补全文字，再次点击才推进。姓名牌随姓名长度和性别变化，旁白不显示姓名牌，句尾小纸飞机轻微浮动。

底栏提供 SAVE / LOAD / Q.SAVE / Q.LOAD、日志、自动、已读快进、隐藏、设置，以及带确认的剧情跳过。跳过沿用游戏原生剧情处理，遇到选项或小游戏停下；确认框可记住“不再提示”。空格隐藏或恢复 UI，上滚打开日志，Esc 关闭日志。T 收起或展开操作栏。

日志全屏半透明、连续滚动，仅建立可见条目，滚动条两端可到顶或到底；人物预览沿用原版历史服饰，有静态表情差分时使用差分，Live2D 暂沿用原版半身预览。对白和选项分别记录跳转位置，点击回转箭头先确认，可记住“不再显示”。日志底部仅有“返回对话”，诊断写后台。完整检查点不再按条数或体积淘汰，快进期间继续记录。新版对话档会将已记录的完整回看状态压缩保存在同一个文件里，读取后恢复对应跳转位置；旧档里只有文字而没有完整状态的记录不能补造。旧版已丢失或尚未适配的状态仍不能凭文字恢复；不能据此称所有历史都可跳转。

## 当前适配范围

当前实现已从主界面回合对白扩展到地图、场景、NPC 窗口及有限白名单原生返回流程；支持保存请求排队，关闭保存窗口会取消它自己的捕获。正在补齐文字播放阶段、自动/快进与限时选项的快照和恢复。

**这些是开发实现范围，并非已完成游戏验收。** 特殊 CG、漫画、小游戏关联及尚未适配的返回回调仍有缺口，可能无法完成快照。目前尚未达到用户要求的“任何对话状态都能成功保存”，不能交付为完成版。

快照包含原版世界模型、当前段落、效果阶段、实际选项、立绘、对话历史、随机状态、待提交引导记录、BGM 和事件继续上下文。读取前严格比对游戏程序集、有效配置、Mod 与插件依赖；不兼容时不猜测恢复。

“能够编译”和“通过测试”分别记录在 [当前状态](STATUS.md)。没有通过的测试不能视为支持。

## 文件与云存档

Windows 文件位置：

```
%USERPROFILE%\AppData\LocalLow\PakyiGame\StudentAge\Saves\<SteamID>\dialogue_<revision>.dsav
```

暂存、备份、设备标识在同一用户数据根目录的 `DialogueSaveLocal\<SteamID>\`，与 BepInEx 插件文件夹分开。删除插件不会触发删档逻辑。移除整个 CrossOver bottle 或清理该用户数据目录仍会移除其中的文件。

每次成功保存发布一个自包含版本。原版仅识别自己的存档扩展名，因此不会把 `.dsav` 当作普通存档。插件不修改普通继续游戏的 `LatestSaveKey`。

当前本机 Steam 配置中，存档顶层目录的 `*` 规则包含 `.dsav`，因此具备沿用 AutoCloud 的路径条件。**这不等于已验证跨电脑同步。** 本地保存完成仅代表写入本机。换电脑还需同一 Steam 账户、对应游戏与相同依赖。Steam 的同步时机和冲突处理由客户端决定：[Steam 官方说明](https://partner.steamgames.com/doc/features/cloud)。

两个设备从同一版本继续保存会保留为分叉，插件不会仅按时间自动覆盖。删除使用持久删除标记，防止旧设备重新同步后使已删版本复活。

当前未提供历史回收，也不再设默认 2 GiB／4,000 文件的历史总量上限；不会为了新档删除旧档。每次写入使用本机跨进程锁、完整性校验与原子发布，槽位变化时保留已有文件。显式配额仅供测试或调用方主动配置。历史增多仍会增加列表扫描成本，磁盘不足须由系统如实报错。

## 本地构建与测试

`tools/build.py` 只读引用本机游戏程序集，输出独立插件 DLL；不安装到正式版。`tests/StorageTests.csproj` 检查落盘、损坏、版本、冲突和配额。`tests/AdapterContractProbe` 只验证当前游戏的反射契约。

`qa/` 中游戏副本、fixture、隔离改写程序集、截图和测试工具仅供本机验证，**不进入分发包**。隔离测试不使用真实玩家存档；正式路径与偏好有前后校验记录。

项目协作总指导：[AGENTS.md](../AGENTS.md)。

## 0.1.1 更新兼容与退出自动保存

读取旧档不再要求相同模组版本、插件构建或全局配置摘要。原文件不重写，仍检查完整性、恢复格式与真实缺失节点。

在对话中返回主菜单或正常退出时尝试保存到独立自动档；保存异常或超时不会阻止退出。Steam 原生模组测试包的目录和使用方式见 [Steam 包说明](WORKSHOP.md)。

漫画演出保留原版文字、字体与位置，隐藏插件底板及右下工具栏；普通对话和真正 CG 不受影响。日志跳转是恢复内存世界检查点，包含效果阶段，选择后的属性/物品/事件等随世界一起恢复；逐句不产生磁盘存档。旧版只有文字而无完整状态的记录仍不能凭空重建。

## 事件与原生对话

选择 ADV 后，只有绑定事件的对白使用 ADV 界面。闲聊等无事件对话仍使用原版界面，不额外显示保存工具栏。原版和剧情模组的原生时间经过/转场期间隐藏插件 UI，演出结束自动恢复。

### 本地保留副本（0.1.5）
对话存档先写入原生本地存档目录，由 Steam 同步。另在游戏持久数据目录下的 `DialogueSaveLocal/<SteamId>/Backups/Retained/` 保留独立副本；Windows / CrossOver 内通常为 `C:\users\<用户>\AppData\LocalLow\PakyiGame\StudentAge\DialogueSaveLocal\<SteamId>\Backups\Retained`。取消订阅不删除这些数据。

已有存档首次扫描时补副本。若云同步目录缺少文件，后台会从通过完整性校验的副本补回，不覆盖同名文件；删除标记也保留，所以主动删除的存档不会重新出现在列表。磁盘不可写、空间不足、强杀或整台机器损坏仍可能使副本未完成。副本失败记后台日志，不将已经成功提交的主存档误报为失败。自动存档历史版本会保留在磁盘，但常规列表仍只显示各槽位最新版本。
