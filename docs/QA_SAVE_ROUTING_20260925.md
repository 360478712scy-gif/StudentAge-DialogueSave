# 0.2.1 保存与读取分流修复（2026-09-25）

原因：AdvSavePage.ClickSlot 仅按 record 是否为空分流，已有档一律读取；Save 又总分配未占用逻辑槽。现按页面决定操作：保存页空槽保存、非空覆盖；读取/快速读取页空槽只提示、已有档读取。覆盖使用 Overwrite 确认，支持取消和关闭确认；底部提示一致。原版分类遵循打开时的保存/读取用途，自动档只读。

同周目覆盖通过已选 revision 与完整父版本校验提交；跨周目使用新检查点＋旧槽删除标记的同一事务，保持新世界 RunId，完整回执及两份 body 齐全才可见。失败/云端缺失成员仍显示旧档。原版覆盖提交新档后更新原位置，移除被替换条目，保留既有备份流程。

验证：112 项存储（含新增覆盖、过期选择、跨周目、缺失回执/新 body、删除不复活旧档）、26 配置、16 历史编解码检查通过；生产 DLL 编译通过。隔离游戏用真实 EventSystem 射线点击验证空槽保存、已有档覆盖、取消不改旧 revision、无确认直接覆盖、覆盖不跳回旧剧情、不新增可见槽、读取空位不写、读取覆盖后选择状态、快速读取空位不写、原版读取空位不写、原版新增与覆盖不多出旧档。测试前两次因脚本未等界面布局/转场失败，补齐等待后通过；不是把失败忽略。正式玩家存档未作为测试夹具，未启动正式游戏。
