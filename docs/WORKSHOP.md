# 对话存档与 ADV 界面 · Steam 模组测试包

适用《学生时代》1.94 内置 BepInEx 5 的版本。使用游戏原生模组加载器，不依赖 UP 或小游戏插件，不附带 BepInEx、游戏程序集、个人存档或测试驱动。

```text
模组根目录/
├── plugins/StudentAgeDialogueSave.dll
├── preview.png
├── manifest.json
└── readme/
```

工坊页面：https://steamcommunity.com/sharedfiles/filedetails/?id=3804899191

Steam 库右键游戏 → 属性 → 测试版 → 选择 test - 测试版，等待更新。订阅后，在游戏模组列表中启用并按游戏提示重启即可；无需手动装加载器。同一插件的手动安装版与订阅版不能同时保留，以免重复加载。

首次进入选择原版或 ADV 风；以后可在设置里切换。对话存档入口与原版手动、自动、快速存档并列。ADV 支持日志回跳、跳过、自动、隐藏 UI 等操作。空格隐藏，滚轮向上打开日志，Esc 关闭日志。

漫画演出仅显示原版文字及原版字体，不显示插件对话底板与工具栏；普通对白和 CG 的 ADV 样式保持不变。

日志回跳使用内存中的世界检查点，恢复属性、关系、物品、事件与选择状态，再恢复对白和效果执行阶段。不创建逐句存档文件、不快进重放中间剧情；手动/自动存档时才把已有回看数据一并写入档案。旧历史缺少真实检查点时无法补造。

存档兼容按存档结构和恢复所需节点判断，不因模组更新、插件版本或全局配置摘要不同而拒读。已被删除的剧情、缺失资源与损坏文件仍可能无法恢复；详细原因记后台日志。旧文件不被重写。

对话中返回主菜单或正常关闭游戏时尝试写入独立的自动对话档。退出保存成功才记成功日志；异常或最多 5 秒等待后仍会退出，不显示阻止退出的提示。强制结束进程、断电、磁盘不可写和未适配的特殊流程不能保证保存成功，已有存档会保留。

对话档与普通存档同目录，独立 `dialogue_*.dsav` 文件。卸载插件不删除档案。目录符合本机观察到的 Steam 云匹配规则；两台设备真实同步尚未验收，不能把本地保存成功当作云同步成功。

本包是开发测试版。具体本轮验证记录与未覆盖项见源码仓库 `docs/STATUS.md`；不要把打包完整性检查等同于全剧情验收。

## 0.1.2 更新

- 带颜色的选项正确显示文字颜色，不再露出格式标签。
- 对话日志跳转后以正常速度停留，等待手动操作；仅关闭日志仍保留之前的播放模式。
- 不满足条件的选项框体持续灰色，文字不变；所有选项仅在悬停时显示原版条件提示（包括已达成条件）；可选状态跟随原生选项刷新。

## 0.1.4

ADV 仅用于事件对白；闲聊等无事件对白保持原版界面且不显示额外保存按钮。原生时间经过/转场（含使用原生演出指令的剧情 Mod）期间隐藏插件界面。减少文字浮现、点击补全时的重复 UI 工作，不改变第一次点击补全、第二次点击推进的操作。

0.1.5：选择 ADV 后普通对白统一使用 ADV。独立本地副本保存在游戏持久目录 DialogueSaveLocal/<SteamId>/Backups/Retained，取消订阅保留；云目录缺失文件时后台恢复，主动删除仍有效。
