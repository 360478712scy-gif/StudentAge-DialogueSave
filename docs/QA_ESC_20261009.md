# 0.2.12 Esc 关闭与发布验收

Esc 按下时按最上层处理：确认框取消、备注编辑取消、存读档关闭、设置取消并放弃草稿、日志关闭。动画或提交中保持输入保护；按键释放帧仍被消费，避免底层暂停菜单重开。原版式对话存档子页和对话外原生存读档同样处理，游戏其他页面维持原生按键。

根因是 ADV 已把存档页计入模态状态，但原关闭函数仅处理日志／确认，遗漏存档页；设置也未加入 Esc 的目标判断。现在所有这些页面沿各自已有取消或关闭入口处理，保持暂停租约及回调清理。
