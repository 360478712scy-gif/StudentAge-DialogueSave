# 0.2.11 历史回跳、跳过与页面范围修复

2026-10-04：完成构建、独立检查和隔离游戏定点回归，已备份并替换本机订阅目录的生产 DLL。没有启动正式游戏。随后按用户“发布”授权更新既有 Steam 工坊条目 3804899191，成功回执及精确 5 文件下载哈希均核对通过。

## 修复及依据

- 历史回跳：0.2.10 的 `backgroundSource` 在内存中可能是值为 null 的 String JValue，校验误报“对话背景图片无效”；落盘再读则变成 JSON null。捕获改为规范 null，验证兼容旧内存空值，实际非空资源仍严格校验。
- 场景跳过：保留原生分支与效果执行，去掉电话期间每 0.1 秒调用下一句的模拟快进。拨通和挂断作为原生演出边界，电话内不提前清空参与者。实际越过的对白进入全局已读。
- 未读限制：使用进入当前句之前的已读状态，首读句结束不会使同一次访问突然允许向前跳一句。被拦截的按钮只播放一次点击音，无推进、弹窗或待执行跳过。新配置默认 `SkipUnread=false`，加载既有显式设置保持原值，未迁移玩家配置。
- 非对话中的保存/加载直接打开原版 `SaveView`；对话中保留 ADV 存档页及明确的“原版界面”入口。
- ADV 原版存档分类的异步信息返回只原位更新卡片，不反复销毁按钮；仅请求当前可见页的信息，避免重复悬停音及按下目标被移除。
- 全局确认钩子只接管对话、存档、设置页面的提示；其他页面保留原版，亦不根据插件“不再提示”设置自动确认。
