# 2026-09-24 追加卡顿优化

只改代码与素材加载时机，不重画 UI，不减少对白、选项或完整回溯数据。生产改动限于 AdvBacklog.cs、AdvDialogueController.cs、AdvSettingsSkin.cs。

## 原因与修改

- 新增对白后原先销毁整个日志窗口。现在保留窗口外壳，更新记录、日期、滚动范围和跳转绑定。
- 滚动反复销毁/创建文字与头像。现在保留最多24个屏外记录行，淘汰仅影响渲染对象；每个缓存行保持原绑定，避免异步头像串人。新历史修订会清空旧行缓存。
- “返回对话”字稿首次打开才处理157万像素，分项定位约219ms。增加“返回对话/恢复默认”分帧预热，每次处理16384像素；用户提前打开仍可走原同步路径，未完成纹理不进入共享缓存，退出时清理临时纹理。解码/上传仍是同步步骤。
- 去掉姓名括号和选项签名的逐帧字符串分配。保留选项顺序、原生对象与ID核对，同一选项资格刷新仍走既有绑定。
